# Building Peep

[Peep](https://peep.fun) brings **onchain discovery, social context and trading** into one workspace.

- Discover tokens and follow market activity.
- Explore posts and wallet activity alongside the chart.
- Move from research to trading in the same product.

Available across web, iOS and Android/Seeker. **Closed beta for user testing.**
